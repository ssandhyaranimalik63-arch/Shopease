🛍️ ShopEase - E-commerce Website

ShopEase is a responsive e-commerce frontend website developed using React.js. It allows users to explore products, search for items, view product details, and manage their shopping cart.

✨ Features

- Display different products
- Search products by name
- Filter products by category
- Sort products by price (Low to High and High to Low)
- View product details
- Add products to shopping cart
- Increase and decrease product quantity
- Remove products from cart
- Calculate total items and total price
- Responsive user interface

💻 Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- React Router DOM
- Context API
- Vite

🚀 Installation and Setup

1. Clone the repository:
   
   "git clone YOUR_GITHUB_REPOSITORY_LINK"

2. Open the project folder:
   
   "cd ShopEase"

3. Install dependencies:
   
   "npm install"

4. Start the development server:
   
   "npm run dev"

5. Open the local URL shown in the terminal.
